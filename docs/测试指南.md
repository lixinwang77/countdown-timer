## 2. 冒烟（P0）

| # | 步骤 | 期望 | 规格 |
|---|------|------|------|
| S1 | 启动 App | 进入设置页；首次约 00:01:00，否则为上次设置时长 | S-01, S-04 |
| S2 | 点「开始」→ 等待归零 | 进入「时间到」；震动/提示音持续响，不只几声就停 | R-01, F-01 |
| S3 | 「时间到」页看按钮 | 有「停止」与「重启」，无「重置」主按钮 | F-02, F-03 |
| S4 | 点「重启」 | 立即按原时长重新倒计时 | F-03 |
| S5 | 再等到「时间到」后点「停止」 | 回到设置页，时长仍为原值 | F-02 |

## 3. 模块用例

### 3.1 设置

| 用例 ID | 优先级 | 步骤 | 期望 | 规格 |
|---------|--------|------|------|------|
| TS-01 | P0 | 滚动时/分/秒 | 值更新正确 | S-01 |
| TS-02 | P0 | 点预设 10/15/30 分 | 滚轮变为对应值 | S-02 |
| TS-03 | P1 | 时长全 0 时点开始 | 按钮不可用或无法进入运行 | S-03 |
| TS-04 | P0 | 设为 2 分钟 → 强杀/重启 App | 设置页仍为 00:02:00 | S-04 |

### 3.2 运行

| 用例 ID | 优先级 | 步骤 | 期望 | 规格 |
|---------|--------|------|------|------|
| TR-01 | P0 | 开始后暂停再继续 | 剩余时间连续，不跳变回满 | R-02 |
| TR-02 | P0 | 运行中点取消 | 回设置页，保留时分秒 | R-03 |

### 3.3 结束

| 用例 ID | 优先级 | 步骤 | 期望 | 规格 |
|---------|--------|------|------|------|
| TF-01 | P0 | 倒计时归零 | 文案「时间到」，显示 00:00:00；震动/提示音持续循环 | F-01 |
| TF-01b | P0 | 「时间到」后等待数秒再点「停止」 | 提示音/震动在点停止前一直响，点后立即停止 | F-01, F-02 |
| TF-02 | P0 | 点「停止」 | 回设置；原时长保留；提示音/震动停止 | F-02 |
| TF-03 | P0 | 设 5 秒 → 到点 → 点「重启」 | 重新从约 5 秒开始 Running | F-03 |
| TF-04 | P1 | 「重启」后再到点 | 再次进入「时间到」，两按钮仍在 | F-01, F-03 |
| TF-05 | P0 | 「时间到」响铃中按音量加/减 | 提示音/震动立即停止；仍在结束页 | F-04 |
| TF-05b | P0 | 后台响铃中按音量加/减 | 提示音/震动立即停止 | F-04 |
| TF-06 | P0 | 「时间到」响铃中按电源键息屏 | 提示音/震动停止 | F-04 |
| TF-07 | P0 | 设数秒 → 开始后立即按 Home 回桌 → 等到点 | 后台即响铃/震动，无需打开 App | F-05 |
