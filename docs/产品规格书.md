# 倒计时器 产品规格书

> **文档目的**：记录当前 APP 已实现功能，确保每个功能可被实现、可被追踪。  
> **技术形态**：Android，Kotlin + Jetpack Compose。  
> **更新日期**：2026-08-01

---

## 1. 产品概述

简洁风格的倒计时 App：设置时长 → 运行 → 结束后提示，并可停止或重新开始。

| 项 | 说明 |
|----|------|
| 包名 | `com.example.countdown` |
| minSdk / targetSdk | 26 / 36 |
| 当前版本 | `versionName` `1.1` / `versionCode` `2`（见 `app/build.gradle.kts`） |

### 1.1 版本号约定

每次**修复 bug**或**增加功能**，必须同步修改应用版本号后再交付：

| 项 | 规则 |
|----|------|
| 修改位置 | `app/build.gradle.kts` 中 `versionName`、`versionCode` |
| `versionCode` | 整数，每次变更至少 +1 |
| `versionName` | 面向用户展示（G-02「关于」）；按语义递增（如 `1.0` → `1.1` 功能/修复，重大不兼容可升主版本） |
| 文档 | 本表「当前版本」与变更登记同步更新；测试指南核对「关于」中版本与本次一致 |

## 2. 功能规格

### 2.1 设置（Setup）

| 功能 ID | 名称 | 说明 |
|---------|------|------|
| S-01 | 时分秒滚轮 | 小时 0–99，分/秒 0–59；首次默认 00:01:00 |
| S-02 | 快捷预设 | 10 / 15 / 30 分钟一键填入 |
| S-03 | 开始 | 时长 > 0 时可点「开始」进入运行 |
| S-04 | 记住时长 | 设置页时分秒变更后持久化；重启 App 后恢复为上次设置 |

### 2.2 运行（Running / Paused）

| 功能 ID | 名称 | 说明 |
|---------|------|------|
| R-01 | 倒计时显示 | 大字号剩余时间；进度条按剩余/总时长比例 |
| R-02 | 暂停 / 继续 | 「暂停」冻结；「继续」从剩余时间恢复 |
| R-03 | 取消 | 回到设置页，保留已选时分秒 |
| R-04 | 亮屏 | Running / Paused 时保持屏幕常亮 |

### 2.3 结束（Finished）

| 功能 ID | 名称 | 说明 |
|---------|------|------|
| F-01 | 时间到 | 归零后仍沿用运行页布局：数字上方显示「时间到」、主时间 `00:00:00`、进度条为空条；震动 + 提示音循环播放，直至用户停止提示（见 F-02～F-04） |
| F-02 | 停止 | 结束态左按钮为「停止」；点击后回到设置页，保留原时长 |
| F-03 | 重启 | 结束态右按钮为「重启」；点击后以本次设置的原时长立即重新开始倒计时 |
| F-04 | 按键静音 | 响铃/震动中按下音量键或电源键，立即停止提示音与震动（前台/后台均生效），仍停留在结束态同页 |
| F-05 | 后台到点响铃 | App 在后台时倒计时归零仍立即响铃/震动，无需回到前台 |

### 2.4 通用

| 功能 ID | 名称 | 说明 |
|---------|------|------|
| G-01 | 顶栏重置 | 更多菜单「重置」随时回到设置页 |
| G-02 | 版本信息 | 更多菜单「关于」可查看应用名称与版本号（versionName） |
