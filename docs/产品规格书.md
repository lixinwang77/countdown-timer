# 倒计时器 产品规格书

> **文档目的**：记录当前 APP 已实现功能，确保每个功能可被实现、可被追踪。  
> **技术形态**：Android，Kotlin + Jetpack Compose。  
> **更新日期**：2026-07-29

---

## 1. 产品概述

简洁风格的倒计时 App：设置时长 → 运行 → 结束后提示，并可停止或重新开始。

| 项 | 说明 |
|----|------|
| 包名 | `com.example.countdown` |
| minSdk / targetSdk | 26 / 36 |

---

## 2. 功能规格

### 2.1 设置（Setup）

| 功能 ID | 名称 | 说明 |
|---------|------|------|
| S-01 | 时分秒滚轮 | 小时 0–99，分/秒 0–59；首次默认 00:01:00 |
| S-02 | 快捷预设 | 10 / 15 / 30 分钟一键填入 |
| S-03 | 开始 | 时长 > 0 时可点「开始」进入运行 |
| S-04 | 记住时长 | 设置页时分秒变更后持久化；重启 App 后恢复为上次设置 |

### 2.2 运行（Running / Paused）

| 功能 ID | 名称 | 说明 |
|---------|------|------|
| R-01 | 倒计时显示 | 大字号剩余时间；进度条按剩余/总时长比例 |
| R-02 | 暂停 / 继续 | 「暂停」冻结；「继续」从剩余时间恢复 |
| R-03 | 取消 | 回到设置页，保留已选时分秒 |
| R-04 | 亮屏 | Running / Paused 时保持屏幕常亮 |

### 2.3 结束（Finished）

| 功能 ID | 名称 | 说明 |
|---------|------|------|
| F-01 | 时间到 | 归零后展示「时间到」与 `00:00:00`；震动 + 提示音循环播放，直至用户停止提示（见 F-02～F-04） |
| F-02 | 停止 | 结束页主操作为「停止」；点击后回到设置页，保留原时长 |
| F-03 | 重启 | 结束页另有「重启」；点击后以本次设置的原时长立即重新开始倒计时 |
| F-04 | 按键静音 | 响铃/震动中按下音量键或电源键，立即停止提示音与震动，仍停留在结束页 |

### 2.4 通用

| 功能 ID | 名称 | 说明 |
|---------|------|------|
| G-01 | 顶栏重置 | 更多菜单「重置」随时回到设置页 |
